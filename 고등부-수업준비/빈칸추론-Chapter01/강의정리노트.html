예제 2020.06 평가원 34 유형 · 빈칸추론 (빈칸 = 마지막 문장) 정답 ② 기본기 점검용
1지문 독해 — 글의 흐름 한눈에
주제: 우리가 보는 것의 대부분은 우리가 기대하는 것이다 (첫 문장 = 주제문)
전개: 주제 제시(see = expect to see) → 예시 1: 모닥불·구름에서 얼굴을 "본다" → 예시 2: 다빈치 — 빈 벽의 얼룩을 응시해 모티프를 찾으라 → 대조 구체화: 불(끊임없이 변하는 시각 정보 → 뇌가 가설 놀이) vs 벽(단서 부족 → 뇌가 더 많은 가설 + 필사적 확인) → 예시 3: 벽의 금 → 코 옆모습 → 얼굴·말·춤추는 사람 → 결론(빈칸): 이런 경우 뇌의 시각 전략은 ___
교재 강조(V focus): 철학적·고난도 문항의 사고력을 기르기 전에, 이 정도 수준은 단순 이해가 되어야 하는 기준 문항. 첫 문장 이후는 전부 같은 내용의 재진술이다.
2구문분석 — 핵심 문장 끊어읽기
A large part / of what we see / is / what we expect to see.
대부분은 / 우리가 보는 것의 / 이다 / 우리가 보기를 기대하는 것
  • what 명사절 — 전치사 of의 목적어(what we see), 보어(what we expect to see)로 두 번 사용
A fire provides / a constant flickering change in visual information / that never integrates into anything solid / and thereby allows the brain / to engage in a play of hypotheses.
불은 제공한다 / 시각 정보의 끊임없이 흔들리는 변화를 / 결코 단단한 어떤 것으로도 통합되지 않는 / 그리고 그렇게 함으로써 뇌가 ~하게 해 준다 / 가설 놀이에 참여하도록
  • that 주격 관계절 — 선행사는 a constant flickering change (단수 → integrates)
  • provides ~ and allows — 동사 병렬 / allow + O + to-V 5형식
  • thereby — "그렇게 함으로써" (앞 내용 전체를 원인으로 받음)
3풀이 순서 — 접근법
  1. 첫 문장에서 등식을 세운다: see = expect to see (이후 문장은 전부 이 등식의 재진술)
  2. 불 vs 벽 대조(On the other hand)에서 이해를 구체화 — 벽은 단서가 없어서 오히려 뇌가 더 많은 가설을 만든다
  3. 빈칸 문장의 In cases like these — 지시어가 앞의 사례 전부를 받으므로, 빈칸 = 지금까지 내용의 총정리
  4. 정답이 명확히 "떠오르기"를 기다리지 말고, 내용 이해를 기준으로 선지 소거로 푼다 (교재 강조)
4선지 분석 — 오답이 오답인 이유
① 무언급 — "방해 정보 무시"는 지문에 나온 적 없음
② 정답 — 마음속 이미지를 세상 밖으로 투영(projecting images from within the mind out onto the world) = 불·벽을 보며 기대하는 것을 형상화해 사물에 입히는 과정 그 자체
③ 무언급 — "실제/상상 그룹으로 분류(categorizing)"는 나온 적 없는 정보
④ 방향 왜곡 — 현실 사물끼리의 연결이 아니라, 현실 사물과 내 머릿속 이미지의 연결임
⑤ 무관 — 원본 이미지의 깨진 부분 복원은 전혀 다른 이야기
5조언 · 팁
학생 지도 포인트: 빈칸 유형에서 "머릿속에 답 문장이 안 떠올라요"라는 학생에게 — 떠올리는 게 아니라 소거하는 것임을 이 문항으로 보여주기 좋다. 또한 다빈치 문장을 처음에 이해 못 해도 괜찮다는 점(뒤의 대조에서 이해됨)을 짚어, 모르는 문장은 보류하고 진행하는 습관을 훈련시킬 것.

문항 01 2009.09 평가원 28 유형 · 빈칸추론 (빈칸 = 마지막 문장) 정답 ⑤ 비유 해석형
1지문 독해 — 글의 흐름 한눈에
주제: 우리를 자유롭게(사적으로) 만들어 준 기술이 동시에 우리를 노출시킨다
전개: 풍요·단독주택·TV·컴퓨터 → 이전 세대는 상상 못 할 사적인 삶(private lives) 가능(이웃·대중교통·극장 사례) → However 대반전: 우리를 군중에서 분리해 준 바로 그 기술이 감시·기록(monitor and record)도 가능케 함 → 모르는 다수가 우리에 대해 무언가를 안다 → 해방시켜 줄 것이라던 기술 = 정보 고속도로인 만큼이나 어항(fishbowl) → 결론(빈칸): 현대사회에서 우리가 발견한 것 = ___
교재 강조(V check): 전반부 = private lives 확산의 재진술 / However 이후 = monitor and record의 재진술 — 글이 딱 두 덩어리.
2구문분석 — 핵심 문장 끊어읽기
However, / the same technologies / that help separate us from the crowds / also make it possible / to monitor and record our behaviors.
그러나 / 바로 그 기술이 / 우리를 군중으로부터 분리하는 것을 돕는 / 또한 가능하게 만든다 / 우리의 행동을 감시하고 기록하는 것을
  • the same ~ that ... — "...한 바로 그 ~" / help (to) separate — help + 원형부정사
  • make it possible to-V — 가목적어 it, 진목적어 to부정사 (모니터링과 기록이 병렬)
The very technology / that was supposed to free us from mass society / has turned out to be / as much a fishbowl as an information highway.
바로 그 기술이 / 우리를 대중사회로부터 해방시켜 줄 것으로 여겨졌던 / ~인 것으로 판명되었다 / 정보 고속도로인 만큼이나 어항인 것으로
  • the very + 명사 — "다름 아닌 바로 그" (강조) / be supposed to-V — ~하기로 되어 있다
  • turn out to be — ~로 판명되다 / as much A as B — B인 만큼이나 A인
3풀이 순서 — 접근법
  1. 빈칸이 마지막 문장 → 결론 = 글 전체 요약임을 확인하고 읽기 시작
  2. However 앞뒤로 글을 두 덩어리로 나눈다: 자유·사생활 ↔ 감시·노출
  3. fishbowl 비유를 추상어로 번역한다: 어항 속 물고기 = 훤히 들여다보이는 존재
  4. 빈칸에는 두 덩어리가 모두 담긴 선지가 와야 함 — 자유(free) + 노출(naked)
4선지 분석 — 오답이 오답인 이유
① 반대 진술 — 혼잡 없이 이동할 수 있게 되었다고 했음 (지문 표현 crowding 재활용 함정)
② 무관 — 자연환경으로부터의 독립은 소재 자체가 없음
③ 무언급 — 풍요의 확산에 대한 "무관심"은 나온 적 없음 (prosperity 단어만 재활용)
④ 무관 — 협력과 잘못된 결론은 전혀 다른 이야기
⑤ 정답 — being free often means also being naked: free = 사적인 삶·해방(전반부), naked = fishbowl 속 노출(후반부). 두 덩어리를 모두 담은 유일한 선지
5조언 · 팁
학생 지도 포인트: 정답 ⑤는 지문 단어를 안 쓰고 비유(fishbowl)를 비유(naked)로 받은 선지 — "빈칸 정답은 패러프레이즈"의 극단적 사례. 오답 ①③은 지문 단어(crowding, prosperity)를 그대로 쓴 전형적 함정 — "낯익은 단어가 보이면 의심하라."

문항 02 2018.04 교육청 33 유형 · 빈칸추론 (빈칸 = 첫 문장) 정답 ② 근거 후치형
1지문 독해 — 글의 흐름 한눈에
주제: 식품업계의 착색(베타카로틴)은 소비자를 속여 행동을 조작하려는 시도다
전개: 도입(빈칸): 식품업계가 합성 베타카로틴 같은 색소를 쓰는 것은 ___하기 위한 시도 → 예시: 마가린 — 원래는 흰색에 기름진 맛인데, 베타카로틴을 넣어 버터처럼 보이고 더 크리미해 보이게 함 → 역사적 근거: 1895년 Petersen 강연 — "왜 마가린을 버터색으로 물들이는가? 답은 하나, 사람들이 버터를 먹고 있다고 믿게 하려는 것" → 결정타: 무해하다고 해도 그것은 "기만(deception)의 목적"으로 행해진 것
교재 강조(V check): 빈칸 문장의 in an attempt to ~ = "~하기 위하여"(인과관계) / 마지막 문장이 핵심 / 키워드 manipulate.
2구문분석 — 핵심 문장 끊어읽기
The addition of beta-carotene / makes margarine look more like butter, / and it appears creamier / than it really is.
베타카로틴의 첨가는 / 마가린이 더 버터처럼 보이게 만든다 / 그리고 그것은 더 크리미해 보인다 / 실제보다
  • make + O + 동사원형(look) — 사역동사 5형식 / appear + 형용사 — 2형식 (~해 보이다)
  • than it really is — 비교급 + 실제와의 대비 ("실제보다 ~하게") — 기만의 뉘앙스가 문법에 이미 들어 있음
the only possible answer to that question is / because it is believed that / it will make people think / that they are in fact consuming butter.
그 질문에 대한 유일하게 가능한 답은 ~이다 / ~라고 믿어지기 때문 / 그것이 사람들로 하여금 생각하게 만들 것이라고 / 자신들이 사실은 버터를 먹고 있다고
  • it is believed that — 가주어 구문 / make people think that ~ — 사역 + that절 (이중 내포)
  • in fact — "사실은" (착각 유도의 핵심어) / that절 안에 that절 — 절 속의 절 구조 훈련용
3풀이 순서 — 접근법
  1. 빈칸이 첫 문장에 있음 → 근거는 반드시 뒤에 나온다 (예시·인용을 끝까지 읽고 판단)
  2. in an attempt to = 목적 표현 → "색소를 쓰는 목적이 무엇인가?"로 질문을 만든다
  3. 마가린 예시에서 방향을 잡고(버터처럼 보이게), 마지막 문장 "purpose of deception"에서 확정
  4. deception(기만)의 패러프레이즈를 선지에서 찾는다 → manipulate(조작하다)
4선지 분석 — 오답이 오답인 이유
① 무관 — 제조 공정 단순화는 소재 자체가 없음
② 정답 — to manipulate customer behavior: deception(기만) = 소비자가 버터라고 믿게 만들어 구매 행동을 조작하는 것
③ 무관 — 부패(spoilage) 최소화는 언급 없음
④ 무관 — 영양 강화는 언급 없음
⑤ 지엽·왜곡 — 맛(taste) 언급은 있지만 색소의 목적은 맛 강화가 아니라 겉모습을 통한 착각 유도
5조언 · 팁
학생 지도 포인트: "빈칸이 앞에 있으면 답은 뒤에 있다" 원칙을 심어주는 대표 문항. 특히 인용문이 나오면 인용문의 마지막 절이 필자의 결론인 경우가 많음을 짚을 것. deception → manipulate 처럼 지문 핵심어와 선지 정답어를 단어짝(패러프레이즈 페어)으로 정리시키면 어휘 학습과 연결된다.

문항 03 2021.09 평가원 32 유형 · 빈칸추론 (빈칸 = 첫 문장 / 실험형) 정답 ② 해석력 측정형
1지문 독해 — 글의 흐름 한눈에
주제: TV 시청 같은 평범한 행동은 주의분산을 통해 고통스러운 자기인식에서 도피하는 수단일 수 있다
전개(실험형 4단 구조): 가설(빈칸): TV 시청조차 어떤 사람들에게는 ___하는 방법일 수 있다 → 방법: 참가자에게 시험 성적에 대한 가짜 피드백(성공/실패)을 주고, 홀로 자연 다큐 영상 앞에 남겨둠 → 결과: 실패 피드백을 받은 참가자가 성공 집단보다 영상을 훨씬 오래 시청 → 결론: TV를 통한 주의분산(distraction)이 실패·자기 불일치의 불편감을 효과적으로 완화 / 대조: 성공한 참가자는 자기 생각에서 벗어나고 싶은 마음이 거의 없었음
교재 강조(V check): 단순 해석력 측정 — 실험 스토리 이해가 곧 정답. (mundane: 보통의)
2구문분석 — 핵심 문장 끊어읽기
Even as mundane a behavior as watching TV / may be a way for some people / to ___.
TV 시청만큼 평범한 행동조차도 / 어떤 사람들에게는 방법일 수 있다 / ~하는
  • as + 형용사 + a + 명사 + as — 원급 비교에서 관사의 어순 도치 (a mundane behavior → as mundane a behavior as) ★판서 포인트
  • for some people — to부정사의 의미상 주어 / a way to-V: ~하는 방법
The researchers concluded / that distraction through television viewing / can effectively relieve the discomfort / associated with painful failures / or mismatches between the self and self-guides.
연구자들은 결론지었다 / TV 시청을 통한 주의분산이 / 불편감을 효과적으로 완화할 수 있다고 / 고통스러운 실패와 연관된 / 또는 자아와 자기지침 사이의 불일치와 (연관된)
  • associated with — 과거분사의 후치수식 (discomfort를 수식) / A or B 병렬: failures or mismatches
  • 이 결론 문장이 빈칸의 정답 근거 — 실험형 지문에서 concluded 뒤가 답이라는 공식 확인
3풀이 순서 — 접근법
  1. 빈칸 문장 = 가설 → "To test this idea"가 보이는 순간 실험형 구조(가설–방법–결과–결론)로 전환해 읽는다
  2. 실험 설계에서 비교 대상을 표시: 실패 피드백 집단 vs 성공 피드백 집단
  3. 결과의 차이(실패 집단이 오래 시청)에서 방향을 잡고, The researchers concluded that ~에서 확정
  4. 결론의 핵심어 distraction + relieve discomfort를 담은 선지 선택
4선지 분석 — 오답이 오답인 이유
① 무관 — 또래(peers)의 불편한 말은 소재 자체가 없음
② 정답 — escape painful self-awareness through distraction: distraction(지문 그대로) + painful failures/mismatches를 "고통스러운 자기인식"으로 압축한 패러프레이즈
③ 왜곡 — 미디어에서 "건설적 피드백"을 받는 게 아니라 피드백에서 도피하는 것
④ 반대 — 주의를 과제로 재집중하는 게 아니라 주의를 분산시키는 것
⑤ 정반대 — 강렬한 자기성찰은 실패 집단이 피하려던 것 (self 단어 재활용 함정)
5조언 · 팁
학생 지도 포인트: 실험형 지문은 "결론 문장(concluded/suggest/show that ~)이 곧 빈칸의 답"이라는 공식을 세워주기 좋은 문항. ⑤처럼 지문의 self 계열 단어를 재활용하되 방향이 정반대인 선지가 최다 오답이 되는 패턴을 보여줄 것. 구문 포인트 "as mundane a behavior as"는 어법 문제로도 출제되는 어순이므로 별도 판서 권장.

문항 04 2011.09 평가원 27 유형 · 빈칸추론 (빈칸 = 첫 문장 주어) 정답 ① 어휘 장벽 돌파형
1지문 독해 — 글의 흐름 한눈에
주제: 정보가 넘쳐날수록 정보를 평가하기는 더 어려워진다 (정보 과부하 → 혼란·결정 회피)
전개: 도입(빈칸): ___은 우리가 쓸 수 있는 정보의 과잉으로 악화된다 → 명백한 사례: MS 주식 가치 평가에 잠재적으로 관련된 정보가 얼마나 많은가 → 확장: 정보가 덜 복잡해 보일 때조차 information overload(혼란과 결정 회피 상태)는 발생 → 실험: 잼 시식 — 적은 종류 vs 많은 종류 → 많은 쪽이 사람은 더 끌었지만 판매는 적은 쪽이 최다 → 이유(마지막 문장): 많은 선택지 → 정보 과부하 → "결정이 너무 복잡하다"는 느낌
교재 강조(V check): aggravated 뜻을 몰라도 선지 소거로 풀 수 있다 / While~ 문장은 완벽 해석 안 돼도 주절 핵심만 / 슈퍼마켓 예시에서 확정 + 마지막 문장에서 확신.
2구문분석 — 핵심 문장 끊어읽기
While everyone likes the idea of abundant choice, / and indeed the table with the greater selection attracted larger crowds, / it was the table with fewer samples / that led to the most sales.
모두가 풍부한 선택이라는 생각을 좋아하지만 / 그리고 실제로 더 많은 종류의 테이블이 더 큰 무리를 끌었지만 / 바로 더 적은 샘플의 테이블이었다 / 최다 판매로 이어진 것은
  • While 양보절 — "~이지만" (두 개의 절이 and로 병렬된 긴 양보절) ← 교재: 완벽 해석 안 돼도 주절만 잡으면 됨
  • it was ~ that ... — 강조구문: 주어(the table with fewer samples)를 강조 ★판서 포인트
  • 대조 포인트: attracted crowds(모으기) ≠ led to sales(사게 하기)
information overload, / a state of confusion and decision avoidance, / can still occur.
정보 과부하 / 즉 혼란과 결정 회피의 상태는 / 여전히 발생할 수 있다
  • 동격 삽입구 — 콤마 사이 명사구가 information overload를 정의 — 필자가 직접 준 단어 뜻풀이는 반드시 표시
3풀이 순서 — 접근법
  1. 빈칸 문장에서 aggravated(악화되다)를 몰라도 멈추지 않는다 — "___이 정보 과잉으로 어떻게든 나빠진다" 정도로 잡고 진행
  2. 동격 삽입구에서 information overload의 정의(혼란·결정 회피)를 확보
  3. 잼 실험에서 방향 확정: 선택지 多 → 구매 少 = 결정이 어려워짐
  4. 마지막 문장 "the decision was too complicated"에서 확신 → 빈칸 = 정보를 평가(assess)하기 어려움
4선지 분석 — 오답이 오답인 이유
① 정답 — Difficulty in assessing information: 정보가 많아질수록 평가·판단이 어려워진다는 글 전체 요약. overload·decision too complicated의 패러프레이즈
② 무관 — 정보원의 "신뢰성"은 소재가 아님 (양의 문제이지 질·신뢰의 문제가 아님)
③ 왜곡 — misleading(오도하는) 정보가 아니라 너무 많은 정보가 문제
④ 왜곡 — indirect(간접) 정보라는 조건은 지문에 없음
⑤ 지엽·왜곡 — 소비자 행동 "변화시키기"의 복잡성이 아니라 소비자 자신의 결정이 복잡해지는 것 (실험 소재 재활용 함정)
5조언 · 팁
학생 지도 포인트: "빈칸 문장에 모르는 단어(aggravated)가 있으면 그 문항은 못 푼다"는 착각을 깨는 문항 — 모르는 단어는 '+/– 방향'만 잡고 통과하는 훈련. 동격 삽입구(콤마, 명사구, 콤마)는 필자가 주는 공짜 힌트임을 강조. it ~ that 강조구문은 이 지문의 실험 결과 문장으로 문법 수업과 연계 가능.
