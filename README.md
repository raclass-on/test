# 📝 여름방학 문법 특강 · 예습·복습 사이트

중학생이 여름방학 동안 영문법을 **문제풀이 중심**으로 예습·복습하는 웹앱입니다.
학생이 **가입 신청 → 선생님(어드민) 승인 → 로그인**하면, 반에 맞는 8개 유닛을
**객관식 40 + 주관식 10 = 50문제**씩 풉니다. 점수는 서버에 저장되어
어드민이 전체 학생의 성취도를 볼 수 있습니다.

## 사용 흐름

- **학생**: 회원가입 신청 → (승인 대기) → 로그인 → 유닛별 문제풀이 → 즉시 채점·해설 → 그날 점수 자동 저장
- **어드민(선생님)**: 로그인 화면의 "선생님(어드민) 로그인" → 가입 승인/거절 + 전체 학생 점수 조회
- **학부모 안내**: 학생 화면의 "학부모 안내" 탭에서 진도 요약을 텍스트로 복사해 전달

## 반 구성 (단계별, 각 8유닛)

- **1-B (1학년 2학기)**: to부정사(목적어) · 비인칭 It · 감각동사+형용사 · 동명사 · 비교급 · 접속사 when · 수여동사 · 명사절 that
- **2-B (2학년 2학기)**: 가주어 It · the 비교급 the 비교급 · 수 일치 · 지각동사 · 목적격 관계대명사 · 접속사 although · 의문사+to부정사 · so~that

문항은 워크북 문제를 약 20% 활용하고 80%는 새로 생성한 뒤, **문법 검수**를 거쳤습니다.

## 아키텍처

- **프론트엔드**: React + Vite (모바일 최적화). `src/` 아래 컴포넌트.
- **백엔드**: Vercel 서버리스 함수 (`api/index.js`) — 가입/로그인/점수/어드민 API.
- **저장소**: Upstash Redis (Vercel 연동). 학생 계정·점수를 서버에 저장.
- **인증**: 비밀번호는 솔트 해시로 저장, 세션은 HMAC 토큰.

## 환경변수 (Vercel)

| 변수 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | 어드민(선생님) 로그인 비밀번호 |
| `AUTH_SECRET` | 세션 토큰 서명용 시크릿(랜덤 문자열) |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | Upstash Redis 연동값 (별칭 `UPSTASH_REDIS_REST_URL` / `_TOKEN` 도 지원) |

## 문제 내용 수정

`src/grammarData.js` 의 해당 유닛 `mc`(객관식) / `sa`(주관식) 항목만 고치면 됩니다.
- 객관식: `{ q, options[4], answer(정답 인덱스 0-3), explain }`
- 주관식: `{ q, answers[](정답 후보), explain }` — 입력값이 후보 중 하나와 일치하면 정답(대소문자·공백 무시)
