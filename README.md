# 📝 여름방학 문법 특강 · 예습·복습 사이트

중학생이 여름방학 동안 영문법을 **문제풀이 중심**으로 예습·복습하는 웹앱입니다.
반(단계)마다 학습 범위가 다르며, 학생별로 그날의 점수와 성취도가 기록됩니다.

## 사용 흐름

1. **로그인**: 반(1-B / 2-B) 선택 → 이름 입력 → 반 비밀번호 입력
2. **문제풀이**: 8개 유닛 중 하나를 골라 **객관식 40 + 주관식 10 = 50문제**를 풉니다.
   각 문제마다 즉시 채점·해설을 보여주고, 끝나면 그날 점수를 기록합니다.
3. **학부모 안내**: 진도 나간 유닛만 「객관식 30/40, 주관식 5/10, 숙제성취도 별4개」 형식으로
   정리해 줍니다. 「텍스트 복사」 버튼으로 문구를 복사해 학부모님께 보낼 수 있습니다.

## 반 구성 (단계별)

- **1-B (1학년 2학기)**: to부정사(목적어) · 비인칭 It · 감각동사+형용사 · 동명사 · 비교급 · 접속사 when · 수여동사 · 명사절 that
- **2-B (2학년 2학기)**: 가주어 It · the 비교급 the 비교급 · 수 일치 · 지각동사 · 목적격 관계대명사 · 접속사 although · 의문사+to부정사 · so~that

각 유닛은 워크북의 기존 문제를 약 20% 활용하고 나머지 80%는 새로 생성했습니다.

## 선생님 설정

- **비밀번호·문구·별점 기준**: `src/config.js` 를 편집하세요.

  ```js
  export const coursePasswords = { '1-B': '1234', '2-B': '1234' }
  ```

- **문제 내용 수정**: `src/grammarData.js` 에서 해당 유닛의 `mc`(객관식) / `sa`(주관식) 항목을 고칩니다.
  - 객관식: `{ q, options[4], answer(정답 인덱스 0-3), explain }`
  - 주관식: `{ q, answers[](정답 후보), explain }` — 입력값이 후보 중 하나와 일치하면 정답(대소문자·공백 무시)

- **점수 기록**: 학생 기기의 `localStorage`에 저장됩니다(반+이름 기준). 별도 서버는 없습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 미리보기
```

모바일 화면에 최적화되어 있으며, React + Vite로 만들어졌습니다.
